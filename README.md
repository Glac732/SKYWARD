# SKYWARD

**Project status: SOURCE PROTOTYPE — NOT A RELEASE BUILD**

SKYWARD is a Unity 6.3 LTS flight-simulation prototype. The implemented scope is one procedurally assembled single-engine trainer and one procedurally assembled demo runway environment. It is not yet the full commercial-style simulator described in the master specification, and it is not certified flight-training software.

## Requirements

- Unity Editor **6000.3.0f1** (Unity 6.3 LTS).
- The Unity Editor components/packages resolved by Package Manager, including URP 17.3.0, uGUI 2.0.0 and Unity Test Framework 1.4.6.
- A desktop system capable of running the Unity Editor. Runtime performance has not been profiled.

## First-time project setup

1. Download or clone the repository.
2. Open the project root in Unity **6000.3.0f1** and allow Package Manager to resolve packages and the Editor to compile.
3. In the Unity menu, choose **SKYWARD → Create / Rebuild Demo Scene**. This creates/configures the URP assets, writes the demo scene and registers it in Build Settings.
4. Open `Assets/Scenes/SKYWARD_Demo.unity`.
5. Press **Play** in the Editor.

The scene is generated by an Editor menu action; a pre-generated `.unity` scene is not currently committed. The first setup step has not yet been verified in a running Unity Editor in this development environment.

## Current controls

| Input | Action |
|---|---|
| W / S | Pitch |
| A / D | Roll |
| Q / E | Rudder |
| Left Shift / Left Ctrl | Increase / decrease throttle |
| Space | Wheel brakes |
| B | Parking brake toggle |
| G | Landing gear toggle |
| F | Cycle flap settings |
| X | Engine toggle |
| C | Cockpit / chase camera |
| Right mouse + move | Camera look |
| Mouse wheel | Chase camera zoom |
| Esc | Pause / resume simulation |

The runtime controller currently reads Unity's legacy `Input` API. Configurable key bindings, the new Input System, gamepad/joystick mappings and mobile touch controls are not implemented.

## Implemented source systems

- Rigidbody-based aircraft force and moment integration.
- Estimated trainer aerodynamic configuration: dynamic pressure, lift, drag, induced drag, flap/gear drag, stall lift reduction, sideslip force, control moments and rate damping.
- Propeller thrust model with airspeed falloff and local fuel consumption.
- Three WheelColliders, suspension/friction setup, steering and wheel braking.
- Gear, engine, flap and parking-brake state controls.
- Procedural trainer geometry and one procedural airport/runway environment.
- Chase/cockpit camera toggle, mouse look and chase zoom.
- Runtime flight HUD and a seven-field cockpit text instrument strip backed by live controller values.
- Local PlayerPrefs save data with a backup key and basic sanitisation.

The trainer model and airport are deliberately primitive/procedural development assets. They are not production aircraft/environment art. The cockpit is not a detailed 3D flight deck.

## Tests and verification

Test source is present for aerodynamic calculations, save behaviour and selected aircraft/ground-contact integration behaviours. **19 test cases are authored** across EditMode and PlayMode assemblies; they have not been executed in Unity in the current environment.

The GitHub Actions workflow checks project metadata, expected package and assembly references, presence of required source files, selected setup-code invariants and basic C# delimiter balance. It is a source-validation workflow only. It does **not** compile Unity C#, run EditMode/PlayMode tests, build a player, inspect rendered graphics, or benchmark performance.

## Not currently delivered

There is no compiled Windows executable/installer, Android APK/AAB, iOS/macOS/Linux player, signed release, or downloadable application build in this repository. There is also no production menu/aircraft or airport selection flow, no complete tutorial/training/career/mission system, no landing score/results screen, no aircraft collection/customisation, no dynamic weather/cloud/time-of-day system, no polished 3D cockpit, no production aircraft/environment/audio assets, no full settings/accessibility/localisation suite, no mobile control system, no multiplayer/backend/cloud save, no content updater, and no measured performance profiles.

Do not present this repository as a finished or release-ready game until those systems are implemented as required and the actual Unity build/test/device checks have passed.

## Recommended verification before any public demo

1. Open the project in the exact Unity Editor version above and resolve all Package Manager/compiler errors.
2. Run all EditMode and PlayMode tests; fix any failures rather than treating the current source-validation workflow as a test pass.
3. Rebuild the scene and inspect the Console for errors/warnings.
4. Play a complete ground-roll → take-off → climb/cruise → approach → touchdown → rollout sequence; inspect gear, braking, control directions, stalls and instruments.
5. Inspect the graphics in Game view at more than one aspect ratio; the existing primitive art should be replaced before presenting the project as premium quality.
6. Build and smoke-test each declared target platform on actual hardware before distributing an installer or mobile package.

Flight coefficients are prototype game-simulation estimates, not validated real-aircraft performance data.
